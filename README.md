# Job Matcher AI

Create a site where I can organize my job search. The initial feature will be processing a @connector:linkedin:"LinkedIn" job post link. First it will check to see if this link, or this specific job, has been processed already. Then it will parse information from the job posting into a cloud database for future reference. After parsing out the information it will use AI to give a matching score, out of 100, as compared to the logged in user's primary resume in the system.
